# Controls 插件

缩放、适应视图、全屏、自动布局等相机操作。

## 界面

左下角垂直按钮栏：

| 按钮 | 功能 |
|---|---|
| + | 放大 x1.2 |
| - | 缩小 /1.2 |
| 适配 | 所有节点适配到视口 |
| 布局 | 自动排列节点 |
| 全屏 | 切换全屏 |

## 右键菜单

注册 "Controls" 子菜单，包含相同操作。

## 内部函数

```ts
do_zoom_in()     // camera.zoom *= 1.2
do_zoom_out()    // camera.zoom /= 1.2
do_fit()         // 计算包围盒适配视口
do_layout()      // 从左到右换行排列
do_fullscreen()  // 切换全屏
```
